# 家庭 subconverter

本仓库提供 `asdlokj1qpi23/subconverter:latest` Compose 模板。实际版本与兼容性须在目标环境验证，不能由 latest 标签推断固定版本或维护状态。

## 部署位置

[Compose](subconverter-compose.yml) 使用 host 网络，在转换器宿主的 25500 端口提供服务。同机调用可用 127.0.0.1:25500，跨机器调用使用宿主实际地址，见 [跨端状态](../../docs/deployment-status.md)。不能把同机调用示例照搬到另一台设备。

部署或升级前核对实际 Compose、运行镜像 ID/digest、网络模式、数据路径及访问范围。保留旧镜像和原 Compose，验证样本包含正在使用的协议与过滤选项；不要用“全协议支持”替代转换结果检查。

## 升级与恢复

按用户授权保存原 Compose 与镜像引用后，再拉取或重建候选。验证 /version、已脱敏样本的节点类型/数量、分组及规则，并逐源区分成功、失败与保留旧数据。

失败时恢复记录的原镜像 ID/digest 与 Compose，用该镜像重新创建容器并验收。**回滚不等于换成另一项目的镜像**；不要把 tindy2013 当作当前 fork 的无条件回退。latest 标签可能移动，未保留镜像就不能承诺精确回滚。

## 验证边界

- /version 成功仅证明服务响应，不证明所有订阅或协议可转换。
- 聚合输出成功不代表每个源成功；检查源状态及节点变化，避免把旧数据当成新拉取结果。
- 缓存、拉取频率和服务商限流按当前版本与真实响应判断，不固定承诺等待若干分钟就恢复。
- sub-web 是可选前端，不能由后端路径推断浏览器能够访问该地址。前端与设备调用分别核实。

真实订阅和认证不写入仓库、日志或 shell 历史。当前实例配置及备份由设备或私有配置维护。
