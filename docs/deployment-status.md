# 部署模式与验收边界

本页描述可选部署模式，不发布任何使用者的设备清单、运行快照、地址映射或维护时间线。模板文件存在不代表设备已部署。

| 场景 | 可选部署方式 | 必须核实 |
|---|---|---|
| Mac | 本机规则脚本，搭配本地或系统 DNS；可选订阅转换器 | 激活订阅、DNS 所有者、TUN/显式代理路径及业务请求 |
| 网关 A | 在同机运行订阅转换器，使用回环地址访问 | 监听、容器网络、转换协议及源状态 |
| 网关 B | 通过 LAN 使用网关 A 的转换器 | 实际后端地址、访问控制、连通性和上游依赖 |
| 个人节点 | 从设备私有源注入，保留节点协议及认证字段 | 持久源、生成结果、组选择与节点业务能力 |
| iPhone | 主页订阅供节点，conf 管分组和规则 | 手机实际激活配置、选择及 Wi-Fi/蜂窝请求 |

网关 A/B 是示意角色，不对应真实设备或固定 LAN 地址。共享转换器会形成订阅更新依赖；不能据此推断具备自动切换、独立灾备或完全相同的节点池。

## 配置所有者

| 内容 | 维护位置 |
|---|---|
| 可复用规则、脚本、Compose 与部署方法 | 本仓库 |
| 私有节点、订阅、组织域名和机器专属例外 | 设备本地或私有配置 |
| 现实状态、决策与带日期的验收记录 | 使用者自己的私有知识库 |
| 最终生效行为 | 设备持久源、生成配置、控制接口与受控请求 |

不要为追求三端数字一致覆盖现有配置。转换器运行状态、每个源是否可用、手机激活状态及终端出口，均须在相应设备上实测。

## 手机验收

在私有记录中保存客户端版本、激活 conf、节点来源、网关/DNS、本机代理开关和组选择；不公开订阅 URL、节点认证或设备身份。分别验证国内、境外、必要内网及业务请求，并区分 Wi-Fi 与蜂窝样本。IPv6、DNS 字段和组数按设备能力验收，无须与 Mac 一致。

## 模板变化后的部署

仓库更新不会自动同步设备。合并时保留本机私有节点和规则，核对专属扩展的覆盖顺序；持久源、生成结果及真实请求通过后，再在私有记录中标注已部署。具体步骤见 [Mac](../clash-verge/README.md) 与 [OpenClash](../openclash/README.md)。
